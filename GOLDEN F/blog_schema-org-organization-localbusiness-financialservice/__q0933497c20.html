Amélioration SEO — Schema.org : Organization + LocalBusiness + FinancialService

Date : 2026-05-04
Priorité : P1 (Élevée) — Action #8 du plan d'action
Catégorie : schema-org
Impact attendu : +15-20 points SEO (structured data 0/100 → 80+/100), rich snippets SERP, CTR +30-50%

Contexte & Problème Identifié

L'audit SEO de goldenfinanceinvestment.fr révèle un score de 0/100 en données structurées (Schema markup). Aucun bloc JSON-LD n'est présent sur le site. Pour un courtier en crédit opérant dans le secteur financier (YMYL — Your Money Your Life), l'absence de Schema markup est particulièrement pénalisante :

  • Pas de rich snippets dans les résultats Google (étoiles, horaires, téléphone, adresse)
  • Pas de Knowledge Panel Google My Business enrichi
  • Pas de visibilité locale renforcée (LocalBusiness)
  • Perte de CTR estimée : 30-50% par rapport aux concurrents avec Schema

Bloc 2 : WebSite + SearchAction (Page d'accueil uniquement)

À ajouter en complément du Bloc 1, sur la page d'accueil uniquement :

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "@id": "https://goldenfinanceinvestment.fr/#website",
  "url": "https://goldenfinanceinvestment.fr/",
  "name": "Golden Finances & Investment — Courtier en Crédit Versailles",
  "description": "Courtier en crédit indépendant à Versailles. Crédit immobilier, rachat de crédits, crédit professionnel. Simulation gratuite, réponse 24h.",
  "publisher": {
    "@id": "https://goldenfinanceinvestment.fr/#organization"
  },
  "potentialAction": {
    "@type": "SearchAction",
    "target": {
      "@type": "EntryPoint",
      "urlTemplate": "https://goldenfinanceinvestment.fr/simulateur.html?montant={search_term_string}"
    },
    "query-input": "required name=search_term_string"
  },
  "inLanguage": "fr-FR"
}
</script>

Bloc 3 : BreadcrumbList (Pages de services)

À ajouter sur chaque page de service (adapter le nom et l'URL) :

Exemple pour la page Crédit Immobilier :

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "Accueil",
      "item": "https://goldenfinanceinvestment.fr/"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "Nos Services",
      "item": "https://goldenfinanceinvestment.fr/nos-services.html"
    },
    {
      "@type": "ListItem",
      "position": 3,
      "name": "Crédit Immobilier",
      "item": "https://goldenfinanceinvestment.fr/credit-immobilier.html"
    }
  ]
}
</script>

Adapter pour chaque page : - /rachat-credits.html → "Rachat de Crédits" - /credit-professionnel.html → "Crédit Professionnel" - /assurance-pret.html → "Assurance de Prêt" - /credit-consommation.html → "Crédit Consommation" - /credit-travaux.html → "Crédit Travaux"

Instructions d'Implémentation Détaillées

Étape 1 — Préparer les fichiers

  1. Ouvrir le fichier source de la page d'accueil (index.html ou équivalent CMS)
  2. Localiser la balise </head> (fin du bloc head)

Étape 2 — Insérer les blocs JSON-LD

Coller les blocs JSON-LD juste avant la balise </head> dans cet ordre : 1. Bloc 1 (Organization + LocalBusiness) → sur toutes les pages 2. Bloc 2 (WebSite + SearchAction) → sur la page d'accueil uniquement 3. Bloc 4 (FAQPage) → sur la page d'accueil ou une page FAQ dédiée

Pour les pages de services, ajouter également : - Bloc 1 (Organization) - Bloc 3 (BreadcrumbList adapté à la page)

Étape 3 — Personnaliser les valeurs ⚠️

Avant de déployer, vérifier et adapter les éléments suivants :

Champ Valeur actuelle À vérifier
logo.url /images/logo.png ✅ Vérifier le chemin réel du logo
image /images/og-image.jpg ✅ Créer l'image OG si absente
geo.latitude 48.8049 ✅ Vérifier sur Google Maps
geo.longitude 2.1256 ✅ Vérifier sur Google Maps
openingHoursSpecification Lun-Ven 9h-18h ✅ Confirmer les horaires réels
sameAs (LinkedIn, Facebook) URLs génériques ✅ Remplacer par les vraies URLs
identifier ORIAS Non inclus ⚠️ Ajouter le numéro ORIAS réel

Ajouter le numéro ORIAS dans le bloc Organization :

{
  "@type": "PropertyValue",
  "name": "ORIAS",
  "value": "VOTRE_NUMERO_ORIAS"
}

Étape 4 — Valider le Schema

Après déploiement, tester obligatoirement avec :

  1. Google Rich Results Test : https://search.google.com/test/rich-results - Entrer l'URL de la page d'accueil - Vérifier qu'aucune erreur n'est signalée - Confirmer les types détectés (Organization, LocalBusiness, FAQPage)

  2. Schema.org Validator : https://validator.schema.org/ - Coller le JSON-LD directement - Vérifier la conformité au standard

  3. Google Search Console (après indexation, 1-2 semaines) : - Aller dans "Améliorations" → "Données structurées" - Vérifier l'absence d'erreurs

Étape 5 — Déployer sur toutes les pages de services

Répéter l'opération pour chaque page de service en adaptant le BreadcrumbList : - /credit-immobilier.html - /rachat-credits.html - /credit-professionnel.html - /assurance-pret.html - /credit-consommation.html - /credit-travaux.html
