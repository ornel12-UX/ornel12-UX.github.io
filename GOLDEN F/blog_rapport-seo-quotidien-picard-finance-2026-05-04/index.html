Description :
Génération de 4 blocs JSON-LD complets et prêts à déployer pour goldenfinanceinvestment.fr : 1. Organization + LocalBusiness + FinancialService — Bloc principal avec adresse, horaires, 6 services, zone d'intervention, identifiants légaux (SIREN, RCS) 2. FAQPage — 5 questions/réponses optimisées pour les featured snippets et la compréhension sémantique

📋 Instructions d'Implémentation Résumées

  1. Ouvrir le fichier source de chaque page (index.html, pages services)
  2. Coller le Bloc 1 (Organization) juste avant </head> sur toutes les pages
  3. Ajouter le Bloc 2 (WebSite) sur la page d'accueil uniquement
  4. Ajouter le Bloc 3 (BreadcrumbList adapté) sur chaque page de service
  5. Ajouter le Bloc 4 (FAQPage) sur la page d'accueil ou une page FAQ dédiée
  6. Personnaliser : vérifier les coordonnées GPS, horaires réels, URLs réseaux sociaux, numéro ORIAS
  7. Valider avec Google Rich Results Test : https://search.google.com/test/rich-results
  8. Vérifier dans Google Search Console après 1-2 semaines d'indexation
